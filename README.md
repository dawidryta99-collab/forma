# FORMA | by Zuzia Fiks

Prototyp aplikacji webowej dla trenerki personalnej.

## Uruchomienie
Otwórz `index.html` w przeglądarce lub opublikuj repozytorium na Vercel jako projekt statyczny (Framework Preset: Other; bez komendy build).

## Uwaga
To wersja demonstracyjna. Dane są przechowywane lokalnie w przeglądarce, nie ma kont ani synchronizacji. Nie używaj prawdziwych danych klientek, danych zdrowotnych ani zdjęć sylwetki.
